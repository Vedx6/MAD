# 1. Create the project folder
flutter create navigation_gesture_windows

# 2. Enter the directory
cd navigation_gesture_windows

# 3. Enable Windows desktop support (this is required for your lab manual)
flutter config --enable-windows-desktop

# 4. Open the project in VS Code
code .

lib/main.dart
lib/home_page.dart
lib/second_page.dart

Back in your VS Code terminal (press Ctrl + `), run:

flutter run -d windows
